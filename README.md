# ParsingBot

Telegram-бот с каталогом парсинга, профилем пользователя и подпиской через ЮKassa. Отдельный API хранит пользователей, сроки подписок и статусы оплаты.

1. Создайте виртуальное окружение и установите зависимости командой `python -m pip install -r requirements.txt`.
2. Скопируйте `.env.example` в `.env`. Укажите токен Telegram, идентификаторы администраторов через запятую и параметры собственного API подписок.
3. Для оплаты задайте идентификатор магазина, новый секретный ключ и URL возврата после оплаты.
4. Из родительской папки запустите `python -m ParsingBot.main`.

Для локальной проверки используйте вымышленные значения и подменяйте вызовы Telegram, API подписок и ЮKassa.
